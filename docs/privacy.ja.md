# プライバシーとデータ

[English](privacy.en.md) · [中文](privacy.zh-CN.md) · [日本語](privacy.ja.md)

行動スタイルを振り返る自己チェックです。チーム内での行動傾向を調べる統計・研究分析のために回答を収集します。

各問の選択、結果、質問・翻訳の版、回答言語、各問と全体の回答時間、選択肢の表示方向と位置、真剣度の自己申告、同意の版と時刻、ランダムなブラウザー識別子を収集します。氏名、電話番号、身分証番号、学籍番号は求めません。識別子は同じブラウザーからの重複回答の確認用であり、一人に一つとは限りません。

回答完了後にCloudflare Pages Functionsで受信し、D1に保存します。統計・研究分析に使用し、公開するのは集計結果のみです。回答は販売しません。現在、自動削除の期限は設定していません。

サイトの配信にはCloudflare、ボット判定にはGeeTestを使用します。これらのサービスは、それぞれのプライバシーポリシーに従い、通信や端末の情報を処理する場合があります。認証トークンは検証に使用しますが、その原文は回答データベースに保存しません。

参加は任意で、いつでもページを閉じられます。回答は完了後にのみ送信されます。送信済みの回答はページを閉じても削除されません。お問い合わせや削除のご相談は下記メールへご連絡ください。実名情報を収集しないため、特定の回答を見つけられない場合があります。

娯楽目的の自己チェックであり、医学・心理・能力の診断や、人を選別する根拠にはなりません。
