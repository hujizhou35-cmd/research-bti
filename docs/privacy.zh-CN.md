# 隐私与数据说明

[English](privacy.en.md) · [中文](privacy.zh-CN.md) · [日本語](privacy.ja.md)

这是一个行为风格自评小测试。你的作答将被收集，用于统计调查与研究分析，以了解团队情境中的行为倾向分布。

我们会收集各题选择、测评结果、题目和翻译版本、作答语言、每题及总用时、选项呈现方向与位置、认真度自评、同意版本与时间，以及随机生成的浏览器标识。我们不要求姓名、手机号、身份证号或学号。浏览器标识用于识别同一浏览器的重复提交，不保证一人一号。

答卷由 Cloudflare Pages Functions 接收并保存到 D1 数据库，仅用于整体统计与研究分析，公开时只展示汇总结果，不出售答卷。当前未设置自动删除期限。

网站通过 Cloudflare 托管，并使用极验 GeeTest 进行人机验证；这些服务可能处理网络请求及设备信息，依各自隐私政策处理。验证令牌用于核验，不保存令牌原文。

参与自愿，可以随时关闭页面；完成作答后才提交答卷。已经提交的数据不会因关闭页面自动删除。如需询问或申请删除，请联系下方邮箱；由于不收集实名信息，可能无法定位某一份答卷。

本测试为娱乐性质的自我评估，结果不构成医学、心理、能力诊断或人员筛选依据。
