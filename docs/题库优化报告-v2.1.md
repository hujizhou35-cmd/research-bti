# 研究生BTI 题库优化报告 v2.1

> 操作对象：`data/questionsv4.json`（version 2.0，80 题，scoringModel `polarity-graded-5`）
> 证据来源：16 种研究生行为原型（R1–R16）× 3 轮独立 AI 虚拟作答，共 12 份报告、约 3840 题次（4 文件）。
> 方法论定位：AI 虚拟测试**仅为题目明显缺陷的快速筛查**，所有结论须经人类预测试的项目分析（P 值、D 值、Cronbach α）验证后方可定稿。
> 本轮交付：**Markdown 诊断+重写报告**，并据此生成新题库 **`data/questionsv5.json`（version 2.1）**。改动 = 18 题重写 + 3 题改主题补『职业规划』内容域（Q13/Q18/Q72）+ 4 个脸谱化极端选项软化（Q25/Q30/Q65/Q76 的 E 项）。计分模型、四维度、八向雷达、总题数(80)、各维题数(20)、priority(娱乐版40) 全部不变；每选项保持五档 value{0,1,2,3,4} 各一。

## 测量学定位说明（为什么这样改）

本量表表面是"娱乐人格鉴定"，内核是面向 SCI 发表的 SJT（情境判断测验）+ 极性五级量表。优化遵循三条经过文献核对的原则：

1. **每题只测一个构念，且不依赖专门知识**——SJT 开发通则要求情境直接对应单一目标构念，且不得让"缺少某类专门知识的人"系统性失分。这直接判定 6 道纯临床/规培题为缺陷题（非临床背景者被迫随机作答）。来源：[SJT 开发与心理测量学综述（BGSU）](https://scholarworks.bgsu.edu/pad/vol6/iss1/1/)、[U.S. OPM: Situational Judgment Tests](https://www.opm.gov/policy-data-oversight/assessment-and-selection/other-assessment-methods/situational-judgment-tests/)。
2. **抑制社会赞许偏差**——中性措辞、去掉"显然正确"选项的道德光环、为"正确"选项加入真实代价、让两极都"可共情而非脸谱化"。这直接判定 Q77/Q64 及若干带极端负面标签的 E 项为缺陷。来源：[Nederhof 1985, 社会赞许应对方法综述](https://onlinelibrary.wiley.com/doi/abs/10.1002/ejsp.2420150303)、[降低社会赞许偏差实务](https://www.openmindglobal.io/blog/how-to-reduce-social-desirability-bias)。
3. **中间项必须是"实质立场"而非"逃避避风港"**——含糊的中点会引发中庸偏误、压缩方差；而本量表把 value=2 定义为"健康边界/健康止损"的具体行为，正是抑制中庸偏误的正确做法，前提是中间项写得足够具体可观察。来源：[Likert 量表与中心趋势（Psychonomic Bull. Rev.）](https://link.springer.com/article/10.3758/s13423-017-1344-2)。

# 第一部分：问卷诊断报告

## 跨维度结构性发现（供人类预测试重点验证）

- **R2 佛系 与 R7 转行 同为 X-A-R-W，四维不可区分**：根因是缺"读研动机/学术认同"内容域题（见第三部分 3.1 缺口）。
- **R14 传播者 与 R15 完美主义者 同被预测为 COPT**：二者在控制点/责任上有真实差异（78% vs 100%、68% vs 90%），但被 4 级粗分归并——属粒度限制，建议人类预测试用连续强度分而非仅看 code。
- 这两点均是**四维框架的固有限制**（CLAUDE.md 锁定四维，本轮不扩维），如实记入局限，不在本轮强行修补。

# 第二部分：逐题优化重写

> 说明：18 题原地重写（不增删题），保持 `polarity-graded-5`——每题恒 5 项、value{0,1,2,3,4} 各一、同维两极雷达兼容。每选项标注 `[pole/value]` 与"捕捉原型"。守 CLAUDE.md 红线：零真实人名、无极端负面标签、消极极不超过"回避/拖延"。维度分布不变（CX/OA/PR/TW 各 20）。

## 维度1 控制点 C/X

**Q5. 你算错一个关键数据、导致全组返工一周，同门追问起来，你开口第一句是：**

A. 是我算错了，责任在我，我马上重做并复核整条流程 `[C/4]`（捕捉原型：R15 完美 / R10 理想 / R4 工具人）
B. 主要是我没盯住，这套流程确实也容易绕，我来重弄 `[C/3]`（捕捉原型：R1 卷王 / R3 焦虑）
C. 有我的疏忽，流程里也确实有坑，先一起把它改对要紧 `[mid/2]`（捕捉原型：R16 跨界 / R13 行政）
D. 这套分析本就容易出岔子，我这次也没多检查一遍 `[X/1]`（捕捉原型：R9 技术 / R12 实用）
E. 这流程谁上手都容易错，不全怪我一个人 `[X/0]`（捕捉原型：R2 佛系 / R7 转行）

`[设计意图]`：测控制点（内/外归因）。原题让 R6/R2 挣扎，是因为把"担责"与"维护形象"耦合在一起。本次把场景固定到"同门追问、开口第一句"这一**可观察言语行为**，五档从"全担→各半→甩锅"平滑递进，归因强度与社交措辞绑定，解决"想甩锅但心虚"无处落点的问题。

**Q11. 组会演示环节，你一个常用操作被资深同门当场指出不规范，你第一反应是：**

A. 是我没练扎实、细节没记牢，回去就补练 `[C/4]`（捕捉原型：R15 / R3）
B. 主要怪我不熟，这操作本身确实也有点反直觉 `[C/3]`（捕捉原型：R1 / R9）
C. 我的生疏和这操作的别扭，都有份，分开看 `[mid/2]`（捕捉原型：R16 / R13）
D. 这操作步骤本就绕，我也是得多上手几次 `[X/1]`（捕捉原型：R12 / R8）
E. 这套规范定得就反直觉，谁头几次都容易错 `[X/0]`（捕捉原型：R2 / R7）

`[设计意图]`：解决盲区题——原 Q11"规培操作"被 7+ 原型标 unrelated。改为任何实操学科都能代入的"组会演示被当场指出"，构念与内/外归因梯度完全保留，去掉临床知识门槛。

**Q15. 你做的一份阶段性成果（报告/数据/作品）交上去被挑出一堆毛病、打回重做，你会想：**

A. 是我没吃透要求、做得不够细 `[C/4]`（捕捉原型：R15 / R10）
B. 主要是我理解偏了，要求本身也一直在变 `[C/3]`（捕捉原型：R3 / R1）
C. 我的疏漏和要求的模糊，都有责任 `[mid/2]`（捕捉原型：R16 / R13）
D. 要求改来改去谁都难做对，我也有能改的地方 `[X/1]`（捕捉原型：R12 / R9）
E. 要求天天变、对方自己都没想清楚，怪不到我 `[X/0]`（捕捉原型：R2 / R7）

`[设计意图]`：原 Q15 绑定"横向项目/甲方"，纯学术型（R10）反复挣扎为盲区。泛化为"阶段性成果被打回"，理工/人文/社科皆可代入；归因梯度不变。

## 维度2 责任倾向 O/A

**Q27. 跨组合作分工没说清，对方把本该他做的一块活塞给你，而你自己也忙得脚不沾地，你会：**

A. 二话不说先把活接过来干完，怕拖累整体进度 `[O/4]`（捕捉原型：R4 工具人 / R11 跟屁虫）
B. 接住这次，同时把"这本是你的活"跟对方挑明 `[O/3]`（捕捉原型：R1 卷王 / R13 行政）
C. 想帮但实在分身乏术，提出我能搭手的部分、其余请他自己扛 `[mid/2]`（捕捉原型：R16 跨界 / R15 完美——守质量边界）
D. 嘴上应着，实际拖着不太动 `[A/1]`（捕捉原型：R3 焦虑——不敢拒绝又委屈 / R12）
E. 直接说这不归我，谁的活谁干 `[A/0]`（捕捉原型：R2 / R5 孤狼 / R7）

`[设计意图]`：补"有限承担/想做但分身乏术"缺口（R4、R3 挣扎点）。原 C 档"明确是你的活"过于干脆，落不下 R4。新增"忙不过来但仍想帮"的实质中间档，使"过度负责→健康边界→推诿"梯度连续，并显式制造"忙"的约束以提高真实性。

**Q32. 导师隔三差五让你帮取快递、订饭、跑私人杂事，最近正撞上你赶实验的节骨眼，你会：**

A. 都接着，导师的事再小也尽量办好 `[O/4]`（捕捉原型：R11 跟屁虫 / R4 工具人）
B. 一般都帮，偶尔实在赶不开才委婉说一声 `[O/3]`（捕捉原型：R3 焦虑 / R8 天选）
C. 顺路的搭把手，明显占用科研时间的会如实说明 `[mid/2]`（捕捉原型：R16 / R13 / 健康边界）
D. 能拖就拖，盼着他改找别人 `[A/1]`（捕捉原型：R2 佛系 / R12）
E. 这本不该我管，找个由头基本都不接 `[A/0]`（捕捉原型：R10 理想 / R5 孤狼 / R7）

`[设计意图]`：Q32 是区分度极佳的"神题"（R11 全 A↔R10 全 E 的连续谱），**予以保留**；仅按反馈补入"撞上赶实验"的产出冲突约束，使 R3"不敢拒绝"的纠结有现实依据、降低无约束下的随意作答。

**Q34. 同门科研受挫、半夜情绪崩溃找你长聊，而你自己明早就有要紧的实验/汇报，你会：**

A. 放下手头一切，陪他聊到他缓过来为止 `[O/4]`（捕捉原型：R4 / R6 社交悍匪——重人际）
B. 认真安慰一阵，也提醒彼此都早点休息 `[O/3]`（捕捉原型：R3 / R11）
C. 先稳住他情绪、给点支持，再建议他找更专业的帮助 `[mid/2]`（捕捉原型：R16 / R13 / 健康边界）
D. 简单宽慰两句，让他先睡、有事白天说 `[A/1]`（捕捉原型：R1 卷王——守住自己的事 / R12）
E. 我也帮不上、自己还一摊事，让他自己缓缓 `[A/0]`（捕捉原型：R5 孤狼 / R2 佛系）

`[设计意图]`：原 Q34 让 R1 卷王三轮全挣扎——温情与自身利益不冲突，无法区分。加入"明早有要紧事"的竞争情境，使"过度共情↔守住边界"成为真实权衡，提升对 R1/R5/R6 的区分。

**Q37. 同学的论文想请你帮跑一大批数据分析，你不是作者、手头也有自己的活，你会：**

A. 答应帮他全跑完，就当举手之劳 `[O/4]`（捕捉原型：R4 工具人 / R6）
B. 帮忙跑，但说清这份工作量得算个贡献/署名 `[O/3]`（捕捉原型：R1 卷王 / R13）
C. 小忙可以搭手，量大就先谈清署名或分工再说 `[mid/2]`（捕捉原型：R12 实用——投入产出 / R16）
D. 推说自己也忙，能不接就不接 `[A/1]`（捕捉原型：R2 / R5）
E. 不是我的活，直接婉拒 `[A/0]`（捕捉原型：R10 理想——非学术不碰 / R7）

`[设计意图]`：补"有条件承担"梯度，让 R4（全 A）与 R12（先谈条件）在 B/C 档分开，提高责任维度上半区区分度，同时承接 R12"评估投入产出比"的选项缺口。

**Q38. 同组的人忙不过来，想把本该他负责的一批事务性工作（收样/登记/跑流程）转给你，你会：**

A. 都接过来，多干点没关系 `[O/4]`（捕捉原型：R4 / R11）
B. 帮一部分，提醒他这些本是他的份内事 `[O/3]`（捕捉原型：R1 / R13）
C. 急的时候搭把手，平时各管各的 `[mid/2]`（捕捉原型：R16 / 健康边界）
D. 偶尔帮一次，次数多了就推 `[A/1]`（捕捉原型：R3 / R12）
E. 各自的活各自负责，我不替他扛 `[A/0]`（捕捉原型：R2 / R5 / R7）

`[设计意图]`：Q38 是全卷被标 unrelated 最高频（7/12）的纯临床题（替收病人/写病历）。泛化为"事务性工作转嫁"，所有学科可代入；责任梯度保留。

## 维度3 沟通模式 P/R

**Q41. 后天要交的东西还没做完，今晚你突然高烧到 39 度、基本干不动了，你会：**
