# 研究生BTI · 数据清洗指南（剔除疑似人机 / 无效作答）

> 配套阅读：字段含义见 [`数据字段说明.md`](./数据字段说明.md)。
> 适用对象：从 `…/api/export?key=…` 下载的 CSV（每行一个完整作答，共 96 列）。
> 目标：在不破坏样本代表性的前提下，识别并剔除「机器人 / 不认真 / 重复」的无效作答，得到干净数据集用于项目分析（P 值、D 值、Cronbach α 等）。

---

## 0. 总原则（先读这条）

1. **采集端不拦人、分析端再筛**：问卷只在"完整作答"时上传，且**不在线拦截**可疑作答（Turnstile 目前是 flag 模式），所有质量信号都落在数据里，由你在清洗阶段决定去留。
2. **预先定标准**：最好在正式施测前就把"剔除规则与阈值"写死（预注册），避免事后挑数据。
3. **分层处理，别一刀切**：把可疑度分成「**硬删**（高把握无效）」和「**标记/敏感性分析**（中等可疑）」两层。对中等可疑者，**剔除前/后各跑一遍主分析**，在论文里报告结论是否稳健。
4. **永远报告 N**：写明初始 N、各规则各剔除多少、最终 N，以及剔除前后关键指标对比。

---

## 1. 可用的质量信号（清洗的"原料"）

| 信号 | 来自字段 | 抓什么 |
|---|---|---|
| 防机器人 | `turnstile`（pass/fail/absent/disabled） | 自动化/脚本提交 |
| 作答时长 | `duration_ms`（总）、`answers_json[*].t`（每题 ms） | 速答（没读题） |
| 认真度自评 | `self_report`（serious/partial/careless） | 自承不认真 |
| 直线作答 | `answers_json[*].pos`（A–E 屏幕位置）、`flipped` | 无脑点同一行 |
| 重复提交 | `client_id`（同浏览器随机串） | 同一人多刷 |
| 作答一致性 | `q1…q80` 原始值、`strength_*` | 维内自相矛盾 / 多元离群 |

> 关键：分析主变量永远是**题号 → value(0–4)**；`pos/flipped` 仅用于质检，不进计分。

---

## 2. 清洗流水线（按顺序执行）

### 步骤 1 · 基本完整性（通常已天然满足）
采集端已保证：必须知情同意、答满全部题、过格式校验才入库。所以一般**无缺失值**。仍建议确认：
- `mode` 与已答题数匹配（娱乐版应有 40 个非空 q，严谨版 80 个）。
- `code` 为 4 位、`strength_*` 在 0–10。

### 步骤 2 · 去重（`client_id`）
- 同一 `client_id` 出现多条完整作答 → **同一人多次提交**。
- 规则：**按 `created_at` 保留第 1 条**（首答最接近真实第一反应），其余删除。
- 注意：`client_id` 是浏览器级，不是人级——同一人换浏览器/设备会有不同 id（无法识别），共用一台机器的不同人会同 id（可能误并）。故只用于"明显重复刷"，不要过度解读。

### 步骤 3 · 机器人（`turnstile`）
- `fail` → **硬删**（验证明确未过）。
- `absent` → **标记**（可能是脚本无令牌，也可能是国内真人没加载上 widget）→ 进敏感性分析；若你的 `pass` 占比很高、`absent` 很低，可考虑一并剔除。
- `pass` → 保留（真人浏览器通过）。
- `disabled` → 该条采集时未启用 Turnstile（历史数据），按其它信号判断。

### 步骤 4 · 速答（`duration_ms` + 每题 `t`）
读题+作答有生理下限，过快即没读。**建议默认阈值（可按分布调整）**：
- **每题中位用时** `median(t) < 2000ms` → 速答嫌疑；
- 或 **总时长** `duration_ms <` 题数 × 1500ms（娱乐版 < 60s、严谨版 < 120s）→ 速答嫌疑；
- 或 **过快题占比** `share(t < 1000ms) > 50%` → 速答嫌疑。
- 处理：满足≥2 条 → **硬删**；只满足 1 条 → 标记。
- 上限提示：单题 `t` 异常大（如 > 5 分钟）多为"中途走开"，分析时对该题用时**截断/Winsorize**，别让它污染总时长。

### 步骤 5 · 直线作答 / 无脑点（`pos` + `flipped`）
本问卷选项**整组翻转随机化**，所以"无脑点同一屏幕位置"的人，记录到的 `value` 会忽高忽低、自相矛盾——**比普通问卷更好抓**。
- **同一 `pos` 的最长连续游程** ≥ 题数 × 0.6（娱乐版≥24、严谨版≥48）→ 直线嫌疑；
- 或 `pos` 分布high度集中（单一位置占比 > 70%）→ 直线嫌疑；
- 交叉验证：上述同时伴随**维内 value 方差异常大/无规律**（因翻转导致同位置 = 不同 value）→ 把握更高。
- 处理：极端（占比>80% 或游程≥题数×0.8）→ **硬删**；中度 → 标记。

### 步骤 6 · 自评不认真（`self_report`）
- `careless`（自承随便选）→ **硬删**。
- `partial`（大致认真、个别随意）→ **标记**，进敏感性分析。
- `serious` → 保留。
- 这是低成本但有效的信号；与步骤 4/5 往往相互印证。

### 步骤 7 · 作答一致性 / 多元离群（统计法，可选但加分）
- **维内一致性**：每维 10/20 题，计算个体维内 SD 或 even–odd 一致性；认真者有结构，乱答者维内混乱。
- **多元离群（马氏距离）**：对四维 `strength_*`（df=4）或对 q 项算 Mahalanobis 距离，取卡方 `p < .001` 为离群 → 标记。
- 处理：一般**标记**进敏感性分析，不单独硬删（统计离群≠无效，可能是真实极端被试）。

---

## 3. 推荐的剔除决策（分层）

**硬删（high-confidence 无效，直接移出主分析）：**
- `turnstile == 'fail'`，或
- `self_report == 'careless'`，或
- 速答达标（步骤 4 满足≥2 条），或
- 极端直线作答（步骤 5 极端档），或
- 去重后多余的重复条目。

**标记 → 敏感性分析（剔除前后各跑一遍，报告稳健性）：**
- `turnstile == 'absent'`（国内加载风险），
- `self_report == 'partial'`，
- 中度速答 / 中度直线，
- 马氏离群 / 维内一致性差。

> 经验法则：**硬删通常应 < 总样本 5–10%**。若硬删比例异常高，先检查阈值是否过严、或招募渠道是否被机器人攻击。

---

## 4. 论文里怎么写（数据质量段落模板）

> 共回收完整作答 N₀ 份。依据预先设定的标准剔除：Turnstile 验证失败 a 份、自评不认真 b 份、作答过快（每题中位 < 2 s 或总时长 < 阈值）c 份、直线作答 d 份、重复提交 e 份，剔除后 N₁ 份纳入主分析。对"可疑但不确定"作答（Turnstile=absent、自评 partial、马氏离群）做敏感性分析，纳入/剔除两种方案下主要结论一致（或：差异见附表）。

---

## 5. 注意事项 / 别踩的坑
- **中庸偏误 ≠ 无效**：大量选"健康中间项(value=2)"可能是真实的"辩证/不极端"，**不要**当瞎答删；本问卷的中间项是有意义的实质立场。
- **极端 ≠ 无效**：有人四维都很极端可能就是这种人；要结合时长/直线/自评等多信号，别仅凭极端就删。
- **`absent` 要小心**：国内访问 `challenges.cloudflare.com` 偶有不稳，`absent` 里混有真人；先看 `pass:absent` 比例再决定。
- **别用单一信号定生死**：尽量"多信号交叉"（如 速答 + 直线 + careless 同时命中 → 几乎可确定无效）。
- **保留原始数据**：清洗在副本上做，永远保留导出的原始 CSV 以备复核。

## 附录：Python / pandas 参考脚本（按需改阈值）

```python
import json
import numpy as np
import pandas as pd

# 1) 读取（utf-8-sig 处理 BOM）
df = pd.read_csv("bti-responses.csv", encoding="utf-8-sig", dtype={"client_id": str})

# 2) 解析 answers_json，派生每题 t / pos 序列
def parse(row):
    try:
        a = json.loads(row["answers_json"])
    except Exception:
        a = {}
    ts = [d.get("t") for d in a.values() if isinstance(d.get("t"), (int, float))]
    poss = [d.get("pos") for d in a.values() if d.get("pos")]
    n = len(a)
    # 最长相同 pos 连续游程
    longest = cur = 0
    prev = None
    for p in poss:
        cur = cur + 1 if p == prev else 1
        longest = max(longest, cur); prev = p
    med_t = float(np.median(ts)) if ts else np.nan
    frac_fast = (np.mean([t < 1000 for t in ts]) if ts else np.nan)
    top_pos_share = (max(pd.Series(poss).value_counts()) / n) if n else np.nan
    return pd.Series({"n_items": n, "median_t": med_t, "frac_fast": frac_fast,
                      "longest_pos_run": longest, "top_pos_share": top_pos_share})

df = df.join(df.apply(parse, axis=1))

# 3) 阈值（按你的数据分布 / 预注册调整）
df["floor_ms"] = np.where(df["mode"] == "fun", 60_000, 120_000)
df["run_thr"]  = np.where(df["mode"] == "fun", 24, 48)

speed_hits = (
    (df["median_t"] < 2000).astype(int)
    + (df["duration_ms"] < df["floor_ms"]).astype(int)
    + (df["frac_fast"] > 0.5).astype(int)
)

# 4) 标记
df["flag_turnstile_fail"] = df["turnstile"].eq("fail")
df["flag_self_careless"]  = df["self_report"].eq("careless")
df["flag_speed"]          = speed_hits >= 2
df["flag_straight"]       = (df["longest_pos_run"] >= df["run_thr"]) | (df["top_pos_share"] > 0.7)

# 重复提交：同 client_id 保留最早一条
df = df.sort_values("created_at")
df["is_dup"] = df.duplicated(subset=["client_id"], keep="first")

# 硬删
hard = (df["flag_turnstile_fail"] | df["flag_self_careless"]
        | df["flag_speed"] | df["flag_straight"] | df["is_dup"])
clean = df[~hard].copy()

# 中等可疑（敏感性分析用）
clean["suspect"] = (clean["turnstile"].eq("absent")
                    | clean["self_report"].eq("partial"))

print(f"初始 {len(df)} → 硬删 {hard.sum()} → 主分析 {len(clean)}（其中可疑 {clean['suspect'].sum()}）")

# 5) 计分核对（与前端一致）：strength = sum(q)/(4*n)*10
qcols = [f"q{i}" for i in range(1, 81)]
def strength(row):
    blocks = {"CX": range(1,21), "OA": range(21,41), "PR": range(41,61), "TW": range(61,81)}
    out = {}
    for k, rng in blocks.items():
        vals = [row[f"q{i}"] for i in rng if pd.notna(row[f"q{i}"])]
        out[k] = (sum(vals) / (4*len(vals)) * 10) if vals else np.nan
    return pd.Series(out)
# clean[["s_cx","s_oa","s_pr","s_tw"]] = clean.apply(strength, axis=1)  # 如需自校验
```

> 说明：脚本是**起点模板**，阈值（`2000ms`、`floor_ms`、`run_thr`、`0.5`、`0.7` 等）请结合你真实数据的分布直方图与预注册标准微调。马氏距离 / Cronbach α 可在 `clean` 上用 `scipy` / `pingouin` 续算。
